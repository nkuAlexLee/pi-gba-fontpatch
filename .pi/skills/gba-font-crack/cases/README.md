# 成功案例库（实录索引）

> **给 AI 的指引**：接到新的字库/文本引擎破解任务时，**先读本目录**找同基板、同引擎或同方法的案例，
> 复用已验证的定位手段和地址映射，不要从零开始。每完成一次成功破解，
> 必须按下方规范归档一个案例文件夹并登记索引。

## 归档规范（每案例一个文件夹）

```
cases/<案例名>/
├── README.md        # 实录：结论速览→侦察→定位→映射→构建→验证→已知问题→复现步骤
├── scripts/         # 本案例的补丁/校验脚本（可直接复现运行）
├── data/            # diff 记录、字形数据、映射表等（脚本可再生的可不存）
└── artifacts/       # 关键截图与验证证据
```

- 脚本必须带自检回路或配套校验脚本；大文件（ROM/整个字库）不入库，存 `data/` 的
  应是**可再生成的最小数据**（diff 段、注入字形、映射表）。
- 外部工程（如 pokeRS_redragon）只归档源码文件（.s/.asm/charmap），ROM 与工具不入库。
