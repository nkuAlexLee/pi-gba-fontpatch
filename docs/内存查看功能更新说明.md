### 5. 使用方法

1. **加载ROM**：点击"载入ROM"按钮选择GBA ROM文件
2. **启用调试**：点击"启用调试"按钮
3. **查看内存**：点击"内存"标签页
4. **跳转内存**：
   - 使用区域选择下拉菜单跳转到不同内存区域
   - 在地址输入框中输入具体地址（如 `0x08000000`）
5. **实时监控**：在调试模式下，内存视图会自动刷新
6. **单步执行**：使用"单步"按钮逐步执行，观察内存变化

### 6. 内存区域映射

- **0x00000000**: BIOS (16KB)
- **0x02000000**: 板载RAM (256KB)
- **0x03000000**: 芯片RAM (32KB)
- **0x04000000**: I/O寄存器 (1KB)
- **0x05000000**: 调色板RAM (1KB)
- **0x06000000**: 视频RAM (96KB)
- **0x07000000**: OAM (1KB)
- **0x08000000**: Gamepak ROM区域0 (32MB)
- **0x0A000000**: Gamepak ROM区域1 (16MB)
- **0x0C000000**: Gamepak ROM区域2 (8MB)
- **0x0E000000**: Gamepak SRAM (64KB)

### 7. 字体破解相关内存区域

对于字体破解，以下内存区域特别重要：

1. **VRAM (0x06000000)**: 字体数据可能存储在VRAM中
2. **ROM区域 (0x08000000+)**: 游戏ROM中的字体数据
3. **工作RAM (0x02000000)**: 运行时加载的字体数据
4. **调色板RAM (0x05000000)**: 字体颜色信息
