## 🔬 调试功能如何辅助字库破解

### 1. 寄存器分析辅助编码识别
- **R1寄存器**: 监控字符编码 (ASCII: 单字节, 中文: 双字节)
- **R0寄存器**: 窗口结构体指针，分析渲染上下文
- **PC寄存器**: 跟踪执行流程，发现新Hook点

### 2. 内存查看发现字库结构
- **ROM区域扫描** (0x08000000): 发现字库存储位置
- **VRAM监控** (0x06000000): 跟踪字符渲染过程
- **工作RAM分析** (0x02000000): 发现运行时字符缓存

### 3. Hook点状态监控
- **GetGlyphWidth** (0x080048EA): 单字符处理分析
- **GetStringWidth** (0x08004CCC): 字符串处理分析
- **DrawGlyphTiles** (0x08006876): 渲染过程分析

### 4. 调试信息深度分析
- 记录每次Hook调用的完整上下文
- 分析ASCII和中文的不同处理路径
- 发现隐藏的字符渲染函数
