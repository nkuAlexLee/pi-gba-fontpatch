# 字库扫描功能说明

## 概述

已重新设计扫描功能，专门服务于字库破解。新的扫描系统提供了针对性的分析工具，帮助识别GBA ROM中的字符编码、字体结构和文本位置。

## 主要功能

### 1. 快速字库扫描
**功能**: 快速扫描ROM中的字体特征
**目标**: 快速识别可能的字体数据区域
**输出**: 
- 字体表位置
- 文本字符串
- 编码特征

### 2. 深度字库分析
**功能**: 多阶段深度分析
**步骤**:
1. 文本模式扫描
2. 字体结构分析
3. 编码模式检测
4. 关键字符串查找

### 3. 文本模式扫描
**功能**: 专门扫描文本字符串
**目标**: 识别游戏中的对话、菜单文本
**特点**:
- ASCII字符串检测
- 置信度评分
- 上下文分析

### 4. 字体结构扫描
**功能**: 分析字体数据结构
**目标**: 定位字体表、字形数据
**特点**:
- 字体表检测
- 字符数量估算
- 对齐方式分析

## 扫描区域

### ROM区域 (0x08000000-0x0E000000)
- **主要目标**: 字体数据存储
- **扫描内容**: 字体表、文本字符串
- **重要性**: ★★★★★

### VRAM区域 (0x06000000-0x06018000)
- **主要目标**: 运行时字体渲染
- **扫描内容**: 图块模式、调色板数据
- **重要性**: ★★★★☆

### 工作RAM (0x02000000-0x02040000)
- **主要目标**: 运行时文本缓存
- **扫描内容**: ASCII字符串、文本缓冲区
- **重要性**: ★★★☆☆

## 使用流程

### 步骤1: 载入ROM
1. 点击"📂 载入ROM"按钮
2. 选择GBA ROM文件
3. 等待加载完成

### 步骤2: 选择扫描模式
1. **快速扫描**: 快速获取字体特征概览
2. **深度分析**: 详细的多阶段分析
3. **文本模式**: 专门扫描文本字符串
4. **字体结构**: 专门分析字体数据

### 步骤3: 配置扫描选项
- ✅ 扫描ROM区域 (推荐)
- ✅ 扫描VRAM区域 (推荐)
- ✅ 扫描工作RAM (可选)
- 🔧 扫描灵敏度: 1-10 (默认5)

### 步骤4: 查看结果
1. **摘要标签**: 总体统计和关键发现
2. **文本模式标签**: 发现的文本字符串
3. **字体结构标签**: 可能的字体表
4. **编码分析标签**: 字符编码模式

## 结果解释

### 置信度评分
- **高 (>80%)**: 非常可能是目标数据
- **中 (30%-80%)**: 可能是目标数据
- **低 (<30%)**: 可能性较低

### 关键发现
- **关键字符串**: 如"NEW GAME"、"CONTINUE"等
- **字体表**: 可能的字体数据结构
- **编码模式**: 字符编码规律

### 性能考虑

### 准确性
- 扫描结果是基于概率的推测
- 需要人工验证关键发现
- 不同游戏可能有不同特征

### 兼容性
- 主要针对Pokemon系列游戏
- 其他游戏可能需要调整参数
- 支持大多数GBA ROM格式
